# reitsnew.wyclab.com

产业园基础设施 REITs 底层资产数据站，纯静态，无构建步骤、无外部依赖、无第三方 JS。

## 目录

```
site/
├── index.html        首页（中国地图 + 省份分布 + 榜单）
├── assets.html       底层资产列表（搜索 / 省筛选 / 排序）
├── asset.html        资产详情（4 张趋势图 + 分期明细），?id=资产ID
├── provinces.html    省份表现（卡片网格）
├── province.html     省份详情（趋势 + 该省资产），?p=省份名
├── assets/
│   ├── style.css     全部样式
│   └── app.js        地图渲染、折线图、格式化
├── data/
│   ├── db.js         业务数据（window.REITS_DB）
│   └── geo.js        中国省界投影后的 SVG path（window.CHINA_GEO）
└── favicon.svg
```

## 本地预览

直接双击 `index.html` 即可（数据用 `<script>` 注入，不受 file:// 的 CORS 限制）。

或起一个静态服务：

```bash
cd site && python3 -m http.server 8080
```

## 部署

站点是纯静态文件，整目录上传即可。绑定 `reitsnew.wyclab.com`：

- **EdgeOne Pages**：新建项目指向 `site/` 目录，添加自定义域名 `reitsnew.wyclab.com`，按提示配置 CNAME。
- **对象存储（COS/OSS）+ CDN**：上传全部文件，开启静态网站托管，默认首页 `index.html`，回源域名绑定。

无需 Node、无需编译、无需服务端。

## 数据更新

数据由仓库根目录的脚本生成，站点只消费产物：

```bash
python3 scripts/build_site.py     # 重新生成 site/data/db.js 与 geo.js
```

上游链路：

```
crawl_catalog.py → download_reports.py → extract_core.py   （运营指标）
                                       → extract_fin.py    （财务指标）
                                       → build_fin_db.py   （公司→资产映射）
                                       → derive_fin.py     （派生指标）
                                       → build_site.py     （站点数据）
```

## 指标口径

| 指标 | 定义 |
|---|---|
| 出租率 | 期末实际出租面积 ÷ 期末可供出租面积，取报告披露值 |
| 租金单价 | 含税，元/㎡/天；原始为元/㎡/月 的已按 ×12/365 折算 |
| 坪效 | 租金收入 ÷ 期末实际出租面积 ÷ 期间月数 × 12（元/㎡/年） |
| 运营净收益率 | （营业收入 − 营业成本/费用 + 财务费用）÷ 营业收入 |
| 省份指标 | 该省「当季有披露值资产」的算术平均，各季样本数可能不同 |

## 明暗主题

- 导航栏右侧胶囊按钮（半明半暗圆形图标）切换明 / 暗，蓝色小圆点表示当前处于「自动」状态。
- 自动规则：**19:00–07:00 深夜模式，其余时间白天模式**；页面停留跨过时间点会在 1 分钟内自动翻转，切回标签页时也会立即校正。
- 手动切换只写入 `sessionStorage`，关闭标签页后回到自动，避免一次误点永久改变外观。
- 主题在 `<head>` 内联脚本中于首屏前应用（`data-theme` 属性），不会出现明暗闪烁；配色全部走 CSS 变量，地图色阶同样跟随主题。

## 地图说明

- 省界采用民政部公布的行政区划边界数据，含台湾、香港、澳门，南海诸岛以插图形式呈现。
- 无常驻资产的省份以浅灰绘制，点击无跳转。
- 气泡位置在省份质心基础上做重叠避让，密集区（长三角）会轻微偏移。

## 已知限制

- 部分基金以单一项目公司持有全部项目（508010 / 508012 / 508019 / 508080），财务只能到基金层，站点只展示其运营指标。
- 早期报告（2021–2023）未强制披露分项目指标，趋势起点参差。
- 资产「本期」取各自最新可得报告期，不同资产可能不在同一季。
